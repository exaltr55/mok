## Delivery formats

Per [content-delivery.md](../../docs/03-systems/content-delivery.md), each module is available as:

- **Text** — these files, rendered in-app.
- **Audio** — narrator voiceover.
- **Short video** — 2–3 minute animated summary.

The line structure in each file is intentional — it tracks breath and pause for audio narration. Preserve it when editing.
