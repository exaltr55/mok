# Enterprise Admin Console (IT/Security)

> Source: §2.3.8 of the Mokshly YouSourceful Platform Design Document.

The Enterprise Admin Console is used by **E2. Enterprise Admin (IT)** — never by HR. It manages identity, security, and compliance for enterprise tenants.

---

## Capabilities

- **SSO** — SAML 2.0, OIDC.
- **SCIM 2.0** provisioning.
- **Session policies.**
- **MFA enforcement.**
- **Audit logs** — 13-month retention, exportable.
- Compliance documentation access.
- **Data residency controls** (US, EU).
